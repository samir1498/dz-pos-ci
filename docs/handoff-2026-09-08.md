## Next task, agreed with Samir

A pure `money` module in `crates/core`, no database:

- `Money` newtype over `i64` centimes, checked arithmetic.
- `pct` half away from zero; TVA grouped per rate, rounded once; global
  discount spread across rate groups; stamp `clamp(1 %, 500, 250 000)`
  centimes, cash only; `net_to_pay`.
- Amount in words fr / en / ar.
- Fixtures as one JSON file under `fixtures/money/` loaded by both
  `cargo test` and a vitest run against `design/shared/money.js`, so Rust
  and TS agree to the centime. Names from `docs/features.md`:
  `money_no_float`, `tva_rounding_once_per_rate`, `tva_rates_table`,
  `stamp_cash_only_clamped`, `words_{fr,ar,en}_golden`, `numbering_gapless`.
- proptest: totals conserve centimes, stamp within bounds.

After that: `crates/api` (axum, checked 0.8.9) with `GET/POST /products`,
then the products screen reading it in a browser.
