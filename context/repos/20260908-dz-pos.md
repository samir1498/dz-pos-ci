## Stack and layout

| Piece | Path | Stack |
|---|---|---|
| Core | `crates/core` | Rust, diesel + bundled SQLite, thiserror; models → repos → services |
| API | `crates/api` | axum on localhost, started by Tauri; the only door into core |
| Desktop | `apps/desktop` (+ `src-tauri`) | Tauri 2, React 19, Vite, Tailwind 4, TanStack Router/Query, vitest |
| Mobile (placeholder) | `apps/mobile` | Expo / React Native |
| Shared TS | `packages/shared` | API client, ts-rs generated types, money display |
| Design tokens | `packages/design` | primitives, semantic roles, CSS output |
| Spec | `docs/features.md`, `docs/architecture.md` | the six rules, fiscal rules table with fixture names |
| Design | `design/` | HTML mockups, tokens, `money.js` first draft of the money rules |
| Planning | `context/` | this pc-ctx store |

## Commands

```
just gates                  # what a PR needs, in order
just e2e                    # browser e2e against a fresh API
just api [port] [db] [origin]   # API with a fresh launch token in .dev/api-token
just dev                    # web UI; needs just api running first
just tauri                  # native window; needs a display, so the laptop
```

Rust lives under `~/.cargo` on the WSL box: `export PATH="$HOME/.cargo/bin:$PATH"`
in a non-login shell.

## Rules that decide things

- `Cargo.toml` `[workspace.lints.clippy]`: `unwrap_used` and `expect_used` denied.
- `.githooks/commit-msg`: every commit needs a `ctx:` trailer
  (`git config core.hooksPath .githooks` once per clone).
- `.github/workflows/ci.yml`: what CI actually runs.
- `.mcp.json`: pc-ctx bound to `context/` when a session starts in this repo.
