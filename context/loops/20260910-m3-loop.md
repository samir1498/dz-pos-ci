# M3 loop

Same machinery as the M2 loop (`context/loops/20260909-m2-loop.md`) and its
lessons. Milestone branch `m3/2026-09-10`, cut from `main` after the M2
checkpoint merged; task branches `m3/<task>` in `.claude/worktrees/<task>`;
the checkpoint PR goes from the milestone branch to `main`.

## Waves

- W0: the two M2 refactors, T10 (avoir Remaining table, kind rules as
  CHECKs) and T11 (zod client, till split), started 2026-09-10 06:33 before
  the plan lens because both are frozen by tests and touch no M3 table.
- W1: T1 (migration 000008) and T0 (yearly reset, migration 000009) once
  W0 frees the two cargo slots; both regenerate `schema.rs`, the session
  regenerates it once more at the second merge.
- W2: T2 suppliers and T4 expenses (both need only T1).
- W3: T3 purchases (needs T2's fiche and T0's series for the bon de
  réception) and T5 stock re-derive.
- W4: T6 dashboard (needs T3, T4, T5) and T7 Excel and labels.
- W5: T8 sweep, combined review, docs, PR.
