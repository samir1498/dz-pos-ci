# Demo loop

Samir, 2026-09-16 evening: "build a loop for the demo of current features,
include mobile, use Maestro for navigating in mobile and recording, use an
emulator, work on the machine you are in." The plan is
`the-demo-video-playwright-records-remotion-cuts`; this file is how it is
run.

## The order

1. T1: a `demo` Playwright project that records 1920x1080 video, French,
   slower pace, own `e2e/demo` folder, ignored by `fr`/`en`/`ar`. Its own
   PR; `just e2e` must not change.
2. T2: the five desktop scenes as specs that perform rather than assert.
   Each scene is a clip; `just demo-clips` names them.
3. T2b: the emulator. Done 2026-09-16: AVD `dinar` on the Windows SDK,
   Expo Go on it loading Metro from this box over `adb reverse`. The plan
   page lists every catch (firewall, IPv6 relay, developer-menu card).
4. T2c: `just demo-phone` (scripts/demo-phone.sh): mints the pairing code
   as the owner, films with `adb shell screenrecord`, runs
   `apps/mobile/maestro/demo.yaml` through the Windows-side Maestro, pulls
   the clip next to the desktop ones. The typed pairing path: the
   emulator's camera cannot read a QR off a monitor.
5. T3: clips to mp4 under `dinar-remotion/public/recordings`, gitignored. Done: `just demo-clips` and `just demo-phone`.
6. T4: the Remotion cut with captions in the product's tokens. Done
   2026-09-16 night: `~/dinar-remotion` renders six feature clips and the
   reel, every cut point and caption in `src/features.ts`.

Every code step is a branch, `dz-review` when it touches money or roles
(the demo touches neither), `just ci` on the mirror, merge. Context
bookkeeping goes straight to `main`. `just disk` before a system image,
before `pnpm install` in `dinar-remotion`, before a render.

## Not in this loop

- Publishing the video anywhere. Landing is still blocked on price and
  the Arabic read.
- The five holds (price, Arabic read, certificate, updater key,
  comptable).
- The shared-lockout question (five wrong passwords lock the PIN too):
  Samir's ruling, not the loop's.
